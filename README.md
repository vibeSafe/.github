## 🚀 What is VibeSafe?

VibeSafe is an open-source DevSecOps toolkit for developers building with AI-native tools like Cursor, v0.dev, Windsurf, and Replit. It's made for speed, built for safety, and crafted for the next wave of software creation.

Modern devs ship faster than ever. Security hasn’t kept up.  
We're changing that.

## ✅ What VibeSafe Detects

- Insecure HTTP Methods (PUT, DELETE)
- Exposed Environment Variables
- Hardcoded Secrets (API keys, tokens)
- Missing HTTP Security Headers
- Directory Traversal Risks
- Open Debug Routes
- Outdated / Vulnerable Packages
- Weak JWT Configs
- Improper Input Validation
- Sensitive Files in Public Repos

**+ AI-Powered Fix Suggestions**

> 10+ built-in security checks  
> 100% free to use  
> 50+ JS libraries supported
